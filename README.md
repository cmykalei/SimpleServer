# Simple Server
A simple TCP client-server implementation in Java.

## Project 🌳
```
.
├── Resolve.java
├── Reverse.java
├── SimpleClient.java
└── SimpleServer.java
```

### Usage
Start the server, then connect with the client:
```bash
javac SimpleServer.java SimpleClient.java
java SimpleServer
java SimpleClient
```

## Commands
1. To start the server use `java SimpleServer`.
2. To connect with the client use `java SimpleClient`.
